Entry for the [make.fun bounty "Everyday Wonder, Two Days to Find the Line"](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3): one sentence, at most 200 characters, that makes a small everyday moment strange and new.

> The elevator doors opened on a stranger humming my mother's lullaby, and for one floor the building felt like home.

`main.ts` writes that sentence to `/output/entry.txt`, validating first that it is 1–200 characters, a single line, and a single sentence ending in a full stop.

Run it with Node 22.18 or later:

```sh
node main.ts
```
